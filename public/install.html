AVMirror

Este computador executa o addon, consulta a Jable.TV e entrega catálogo, metadados e reprodução ao Stremio. Nenhum servidor central é necessário para usar a instalação.

Instalar no Stremio

Baixar servidor

v26.1.3

Instale o servidor neste computador. O pacote já inclui a aplicação, Node.js, Chromium/Playwright, idioma inglês, capas e proxy HLS.

Baixar para Windows x64Baixar para Linux x64

Windows: extraia o ZIP e execute o instalador incluído. Linux: abra o arquivo `.deb` para instalar; o serviço será configurado para iniciar automaticamente.

01 · Fonte

Jable.TV

O addon expõe somente a Jable.TV e rejeita IDs e streams de fontes antigas.

02 · Execução

Seu computador

Catálogo, resolução do player e cache em memória ficam no servidor desta instalação.

03 · Reprodução

Proxy HLS local

O proxy local é ativado por padrão para clientes Android e TV que não repassam headers.

Instalação em outro dispositivo

Abra esta página pelo IP LAN do computador servidor. O endereço abaixo deve começar com o IP desse computador, não com `127.0.0.1`.

http://IP-DO-PC:7000/install

O celular/TV e o computador servidor precisam estar na mesma rede. Libere a porta 7000 no firewall quando necessário.

Diagnóstico

Consultando o servidor...

Se o catálogo aparecer vazio, verifique a conexão com a internet e se o Chromium está instalado. O site pode apresentar um desafio Cloudflare; o addon usa o navegador local para tentar concluir essa etapa.
