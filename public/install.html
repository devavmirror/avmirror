Stremio · Windows/Linux

Addon AVMirror Local

Esta é a mesma página principal do AVMirror. O nome exibido no Stremio acompanha a origem: AVMirror Local para o servidor pessoal e AVMirror para o endereço online.

ID técnico local: com.avmirror.addon.local.

Nuvio · addon de catálogo

Catálogo e metadados

No Nuvio, instale o manifesto do addon para visualizar o catálogo AVMirror, AV01 e JavRider. Use o endereço online ou o manifesto do seu servidor pessoal.

ID online: com.avmirror.addon. No servidor local, use o mesmo endereço exibido acima.

Nuvio · plugin opcional

Resolver direto no aparelho

O plugin complementa o addon de catálogo. Ele tenta resolver AV01, AVMirror e JavRider diretamente no celular, entregando a URL ao player do Nuvio. Não é um catálogo separado e não mantém um proxy HTTP contínuo.

Downloads · 26.1.x

Servidores autoatualizáveis

Os launchers verificam commits novos no GitHub, baixam o código da aplicação e reiniciam o servidor atualizado. Assim, novas fontes e funções importantes não exigem um novo empacotamento. O runtime Node e o Chromium continuam incluídos.

O que passa por cada componente?

Modo local

Stremio/Nuvio consultam seu PC. Com proxy ativo, playlists e segmentos passam pelo seu PC.

Modo online

O servidor online pode fornecer catálogo e resolver streams. O vídeo direto vai da fonte ao player.

Modo Nuvio direto

O plugin consulta a fonte no próprio aparelho e o player baixa os segmentos diretamente.
