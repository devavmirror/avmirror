AVMirror

Stremio

Modo direto

O addon entrega a URL original e os headers necessários. O vídeo não precisa passar pelo Render.

Nuvio

Resolução no aparelho

O provider JavaScript usa o dispositivo do usuário para consultar e resolver fontes compatíveis.

Opcional

Proxy local

Instale o servidor local somente quando uma fonte exigir reescrita HLS, cookies ou headers especiais.

Android · Nuvio

Provider direto, sem servidor central

No Nuvio, adicione o manifesto abaixo em Configurações → Plugins. O provider não depende do Render ou de um proxy remoto; o player acessa diretamente a fonte quando ela permite.

https://raw.githubusercontent.com/devavmirror/avmirror/main/nuvio/manifest.json
Abrir manifesto Nuvio

Fontes que exigem navegador completo ou proxy HLS contínuo podem não funcionar no provider direto.

Stremio

Instalar o addon

Use o botão automático ou copie o manifesto. O endereço é calculado com base no host em que esta página foi aberta, o que evita links fixos incorretos em uma rede local.

Servidor local opcional

Quando usar os bundles

Use Windows ou Ubuntu/Debian somente para fontes que não reproduzem no modo direto. Os bundles incluem o runtime e os componentes necessários ao servidor local.

Windows

Bundle x64 com executável, Chromium e instalador PowerShell.

Baixar Windows

Ubuntu / Debian

Pacote DEB x64 com runtime e Chromium Headless Shell.

Baixar DEB

Depois de iniciar o servidor, abra esta página pelo IP do computador. Para ativar o proxy: USE_LOCAL_HLS_PROXY=true.

Fluxo de reprodução

1. Catálogo

O cliente consulta o catálogo e os metadados disponíveis.

2. Resolução

O provider tenta obter um link direto e envia os headers necessários.

3. Reprodução

O player baixa o vídeo da fonte. O proxy local só entra quando habilitado.
