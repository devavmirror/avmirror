# AVMirror v26.1

## Downloads

- `avmirror-windows_26.1.zip`: bundle Windows x64 autocontido com executável e Chromium.
- `avmirror-linux_26.1_amd64.deb`: pacote Ubuntu/Debian x64 autocontido com Node.js e Chromium Headless Shell.
- `avmirror-android_26.1.apk`: APK Android com WebView/Chromium oculto e serviço foreground.
- `SHA256SUMS-v26.1.txt`: checksums SHA-256 dos artefatos.

## Observações

Windows e Linux incluem o runtime e o navegador headless necessários para o servidor local. O APK Android contém a camada WebView e o serviço foreground; o servidor Node completo ainda não é hospedado dentro do APK.

Use apenas fontes e conteúdos para os quais você possui autorização. Não exponha a porta local 7000 diretamente à Internet sem autenticação e TLS.
